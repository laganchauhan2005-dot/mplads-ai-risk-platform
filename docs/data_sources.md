# MPLADS Data Sources

The project uses official MPLADS/eSAKSHI datasets.

Raw datasets are maintained locally and are not committed to this
repository because of their size.

Datasets:
- Allocated Limit for Hon'ble MPs
- Works Recommended
- Works Sanctioned
- Works Completed
- Expenditure on Completed and On-going Works as on Date

Both Lok Sabha and Rajya Sabha datasets are used.

The raw files are processed by the project's preprocessing pipeline
to generate the canonical project dataset.
