# mplads-ai-risk-platform
AI-powered risk and anomaly intelligence platform for MPLADS — SIH26102


## Live ML Prediction
Use Intelligence → Live Prediction to enter a project manually or upload a CSV. The backend runs the current unsupervised cost, progress/delay and duplicate signals, stores the prediction, and upserts an existing project when project_id already exists.

The database contains 98,646 projects plus a synthetic development-only progress/delay layer.
